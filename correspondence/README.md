# Заочная форма обучения

**Дисциплина:** Программирование на языке Java  
**Объём контакта:** 1 вводная лекция + самостоятельная работа + зачёт  
**Основное задание:** [контрольная работа](control-work.md)

## Чем отличается от очной формы

| | Очная | Заочная |
|---|--------|---------|
| Лекции | 8 × ~90 мин | **1 вводная** (обзор курса и старт) |
| Практики | 16 занятий | в КР входят **практики 1–10** (как у очников) |
| РГР | обязательна | вместо неё — **интеграционное задание** в КР |
| Практики 11–16 | потоки, Spring | **не сдаются** |
| Контроль | практики + РГР + тест | **КР** + зачётный тест / собеседование |

## Вводная лекция

Текст и слайды: [lectures/zaoch-intro/](../lectures/zaoch-intro/).

На лекции: JDK и первая программа, карта курса, отличия Java от C++, состав КР (практики 1–10 + интеграционное задание), ссылки на литературу и студенческий репозиторий.

## Что сдавать

1. **Контрольная работа** — практики 1–10 + интеграционное задание + отчёты (см. [control-work.md](control-work.md)).
2. **Зачёт** — итоговый тест и/или защита КР (по решению преподавателя).

## Рекомендуемое ПО

- JDK **25 LTS** (минимум 21+)
- IntelliJ IDEA Community / VS Code + Extension Pack for Java
- Git + личный репозиторий GitHub
