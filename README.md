## Как выбрать вариант

Номер варианта: `(N - 1) mod 20 + 1`, где `N` — номер в журнале (если преподаватель не указал иное).  

## Рекомендуемое ПО

- JDK 25 LTS (или 21+)
- IntelliJ IDEA Community / VS Code + Extension Pack for Java
- Maven или Gradle — для практики 15 и при необходимости для РГР
- Инструменты качества: см. [quality-tools.md](resources/quality-tools.md)

## Тематический план (кратко)

**Очная форма**

| № | Тема лекции | Практики |
|---|-------------|----------|
| 1 | Введение в Java, JVM, синтаксис | П1–П2 |
| 2 | ООП: классы, наследование, полиморфизм | П3–П4 |
| 3 | Интерфейсы, лямбды, пакеты | П5–П6 |
| 4 | Исключения, дженерики, коллекции | П7–П8 |
| 5 | I/O, стандартная библиотека, SOLID/GRASP и паттерны | П9–П10, П12 |
| 6 | Основы многопоточности | П11, П13 |
| 7 | Concurrent-утилиты | П14 |
| 8 | Введение в Spring | П15 |

**Заочная форма:** одна вводная лекция + [контрольная работа](correspondence/control-work.md) (практики **1–10** + интеграционное задание; практики 11–15 и РГР не сдаются).
