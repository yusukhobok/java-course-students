# Практические занятия — оглавление

**Варианты:** в каждой практике **21 вариант** — по числу студентов в потоке (группы БОМ31ПРИ и БОМ31ТВР). Кто какой вариант получает — в таблице «Выбор варианта» внутри файла практики (по фамилии, без формулы).  
Исключение: в [практике 5](05-interfaces-abstract.md) дополнительно паттерн GoF — 22 паттерна, по одному на человека.

**Окружение:** JDK **25 LTS** (минимум 21+).

**Задачник** (для практик 1–2): [resources/zadachnik-2026.md](../resources/zadachnik-2026.md).

Выполнять **один и тот же номер варианта** на протяжении семестра

**Отчёт:** по каждой практике сдаётся **печатный отчёт**. Состав указан в разделе «Состав отчёта» внутри файла практики (титул, постановка, ход, листинг, результаты).

**Git/GitHub:** решения по практикам вести в Git и публиковать в личном репозитории GitHub (регулярные коммиты по мере выполнения работы).

**Качество кода:** перед сдачей проверять проект инструментами контроля качества:
- форматирование кода (formatter);
- статический анализ и стиль (linters);
- базовые автоматические тесты ключевой логики (unit tests).

Как настроить и запускать: [resources/quality-tools.md](../resources/quality-tools.md) (Spotless / Checkstyle / JUnit 5, либо через IDE).
