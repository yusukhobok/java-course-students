## Общая постановка

1. Реализуйте обобщённую структуру данных варианта (`Stack<T>`, `Queue<T>`, …).
2. Реализуйте обобщённый алгоритм/утилиту из таблицы (часто с `T extends Comparable<T>`).
3. Класс `Pair<A,B>` (или аналог варианта) с фабричным методом `of`.
4. Проверьте структуру минимум на двух разных типах-параметрах.
5. Добавить метод с wildcard по правилу PECS.

Пустая структура при `pop`/`dequeue` → unchecked-исключение.

## Варианты

| № | Тема | Структура `<T>` | Утилита |
|---|------|-----------------|---------|
| 1 | Библиотека | `Stack<T>` | `max(List<T>)` для `Comparable` |
| 2 | Магазин | `Queue<T>` (кольцевой массив) | `min(List<T>)` |
| 3 | Университет | `Stack<T>` | `swap(T[] , i, j)` |
| 4 | Склад | ограниченный `Buffer<T>` (ёмкость N) | `firstGreaterThan(list, threshold)`* |
| 5 | Банк | `Stack<T>` | сортировка массива `T[]` пузырьком |
| 6 | Почта | `Queue<T>` | подсчёт вхождений `T` в `List<T>` |
| 7 | Задачи | `Stack<T>` | уникальные элементы → `List<T>` |
| 8 | Чат | `Queue<T>` | `reverse(List<T>)` |
| 9 | Игры | `Stack<T>` инвентарь | `max` из трёх `T` |
| 10 | Метео | `RingBuffer<T>` | среднее для `T extends Number` |
| 11 | Больница | `Queue<T>` | найти индекс элемента |
| 12 | Транспорт | `Stack<T>` | проверить палиндром списка |
| 13 | Кино | `Queue<T>` | взять последние k элементов списка |
| 14 | Отель | `Stack<T>` | объединить два списка без дубликатов |
| 15 | Автосервис | `Queue<T>` | удалить все вхождения value |
| 16 | Музей | `Stack<T>` | `min` и `max` одной функцией → `Pair<T,T>` |
| 17 | Фитнес | `Queue<T>` | циклический сдвиг списка на k |
| 18 | Аэропорт | `Stack<T>` | проверка скобочной последовательности через стек `Character` |
| 19 | Ресторан | `Queue<T>` | `sum` для `List<? extends Number>` |
| 20 | Такси | `Stack<T>` | `copy(List<? extends T>, List<? super T>)` (PECS) |
| 21 | Школа | `Queue<T>` | `indexOfMin(List<T>)` для `Comparable` |

\*Для варианта 4 `threshold` того же типа `T extends Comparable<T>`; переполнение `Buffer<T>` при `push` сверх ёмкости N — тоже unchecked-исключение (как и pop/dequeue из пустой структуры).
