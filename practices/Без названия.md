## Варианты

### Вариант 1. `Box<T>` и `contains`

**Класс `Box<T>`** — коробка, в которой лежит одно значение любого типа.

- `void set(T value)` — положить значение;
- `T get()` — достать значение; если коробка ещё пустая, бросает `IllegalStateException("Коробка пуста")`;
- `boolean isEmpty()` — `true`, пока значение не положили;
- `toString()`: `Box[пусто]` или `Box[42]`.

**Метод `static <T> boolean contains(T[] arr, T x)`** — проверяет, есть ли `x` в массиве `arr`. Сравнивайте через `Objects.equals(e, x)`, не через `==`.

**Пример `main` и вывод:**

```
Box<Integer> b1 = new Box<>();System.out.println(b1);                    // Box[пусто]b1.set(42);System.out.println(b1 + " " + b1.get());   // Box[42] 42Box<String> b2 = new Box<>(); b2.set("Java");System.out.println(b2);                    // Box[Java]System.out.println(Utils.contains(new Integer[]{1, 2, 3}, 2));   // trueSystem.out.println(Utils.contains(new String[]{"a", "b"}, "z")); // falsenew Box<String>().get();                   // Ошибка: Коробка пуста
```

### Вариант 2. `Stack<T>` и `max`

**Класс `Stack<T>`** — стек: последний положил, первый достал. Внутри — `ArrayList<T>`; «вершина» — последний элемент.

- `void push(T x)` — добавить в конец списка;
- `T pop()` — убрать и вернуть последний элемент; на пустом бросает `IllegalStateException("Стек пуст")`;
- `T peek()` — вернуть последний, не убирая; на пустом — то же исключение;
- `int size()`, `boolean isEmpty()`;
- `toString()`: `Stack[10, 20, 30]`.

**Метод `static <T extends Comparable<T>> T max(List<T> list)`** — наибольший элемент списка. Запись `T extends Comparable<T>` значит: «подойдёт любой тип, элементы которого можно сравнить через `compareTo`» (числа, строки). Для пустого списка бросьте `IllegalArgumentException("Список пуст")`.

**Пример:**

```
Stack<Integer> s = new Stack<>();s.push(10); s.push(20); s.push(30);System.out.println(s + " peek=" + s.peek() + " pop=" + s.pop() + " " + s);// Stack[10, 20, 30] peek=30 pop=30 Stack[10, 20]System.out.println(Utils.max(List.of(3, 17, 5)));                  // 17System.out.println(Utils.max(List.of("слива", "яблоко", "груша"))); // яблокоnew Stack<String>().pop();                // Ошибка: Стек пустUtils.max(new ArrayList<Integer>());      // Ошибка: Список пуст
```

### Вариант 3. `Queue<T>` и `min`

**Класс `Queue<T>`** — очередь: первый пришёл, первый ушёл. Внутри — `ArrayList<T>`: добавляем в конец, достаём из начала (`remove(0)`).

- `void enqueue(T x)` — встать в конец;
- `T dequeue()` — убрать и вернуть первого; на пустой бросает `IllegalStateException("Очередь пуста")`;
- `T peek()` — посмотреть на первого, не убирая; на пустой — то же исключение;
- `int size()`, `boolean isEmpty()`;
- `toString()`: `Queue[A, B, C]`.

**Метод `static <T extends Comparable<T>> T min(List<T> list)`** — наименьший элемент списка. Для пустого списка — `IllegalArgumentException("Список пуст")`.

**Пример:**

```
Queue<String> q = new Queue<>();q.enqueue("A"); q.enqueue("B"); q.enqueue("C");System.out.println(q + " dequeue=" + q.dequeue() + " " + q + " size=" + q.size());// Queue[A, B, C] dequeue=A Queue[B, C] size=2System.out.println(Utils.min(List.of(8, 3, 9)));        // 3System.out.println(Utils.min(List.of("b", "a", "c")));  // a
```

### Вариант 4. `Pair<A, B>` и `swap`

**Класс `Pair<A, B>`** — пара значений **разных** типов (например, название и год). У класса два параметра типа.

- два закрытых `final`-поля `first` (тип `A`) и `second` (тип `B`);
- конструктор сделайте `private`, а создавайте пару фабричным методом `static <A, B> Pair<A, B> of(A first, B second)`;
- `A first()`, `B second()` — геттеры;
- `toString()`: `(Java, 25)`.

**Метод `static <A, B> Pair<B, A> swap(Pair<A, B> p)`** — возвращает **новую** пару с поменянными местами значениями. Типы тоже меняются местами: из `Pair<String, Integer>` получается `Pair<Integer, String>`.

**Пример:**

```
Pair<String, Integer> p = Pair.of("Java", 25);System.out.println(p + " -> " + Utils.swap(p));   // (Java, 25) -> (25, Java)Pair<Double, Boolean> p2 = Pair.of(1.5, true);System.out.println(p2 + " -> " + Utils.swap(p2)); // (1.5, true) -> (true, 1.5)
```

Заметьте: компилятор сам знает, что `Utils.swap(p).first()` — это `Integer`, без приведения типов.

### Вариант 5. `Counter<T>` и `mostFrequent`

**Класс `Counter<T>`** — считает, сколько раз встретился каждый элемент. Внутри — `Map<T, Integer>` (ключ — элемент, значение — счётчик) и поле `total`.

- `void add(T x)` — увеличить счётчик элемента `x` на 1 (если его не было — начать с 1); `total` тоже +1. Удобно: `counts.merge(x, 1, Integer::sum)`;
- `int count(T x)` — сколько раз встречался `x`; если не встречался — 0 (не исключение);
- `int total()` — сколько всего элементов добавлено;
- `toString()`: `Counter{a=3, b=2, c=1}` (используйте `LinkedHashMap`, чтобы порядок был предсказуемым).

**Метод `static <T> T mostFrequent(List<T> list)`** — самый частый элемент списка (при равенстве — любой из лидеров). Для пустого списка — `IllegalArgumentException("Список пуст")`. Можно использовать свой `Counter` или `Map`.

**Пример:**

```
Counter<String> c = new Counter<>();for (String w : "a b a c a b".split(" ")) c.add(w);System.out.println(c + " a=" + c.count("a") + " z=" + c.count("z") + " total=" + c.total());// Counter{a=3, b=2, c=1} a=3 z=0 total=6System.out.println(Utils.mostFrequent(List.of("a", "b", "a", "c", "a", "b"))); // aSystem.out.println(Utils.mostFrequent(List.of(1, 2, 2, 3)));                   // 2
```

### Вариант 6. `Registry<K, V>` и `findKey`

**Класс `Registry<K, V>`** — «реестр»: словарь, где ключи типа `K`, значения типа `V`. Внутри — `LinkedHashMap<K, V>`.

- `void put(K key, V value)` — записать;
- `V get(K key)` — прочитать; если ключа нет, бросает `NoSuchElementException("Нет ключа: " + key)`. Это отличие от обычного `Map.get`, который вернул бы `null`;
- `boolean containsKey(K key)`;
- `Set<K> keys()` — все ключи (вернуть `map.keySet()`);
- `toString()`: `Registry{Иван=20, Мария=25}`.

**Метод `static <K, V> K findKey(Registry<K, V> r, V value)`** — возвращает первый ключ, у которого значение равно `value` (сравнение через `Objects.equals`), или `null`, если такого нет. Обход — по `r.keys()`.

**Пример:**

```
Registry<String, Integer> r = new Registry<>();r.put("Иван", 20); r.put("Мария", 25); r.put("Пётр", 25);System.out.println(r);                       // Registry{Иван=20, Мария=25, Пётр=25}System.out.println(r.get("Иван"));           // 20System.out.println(Utils.findKey(r, 25));    // МарияSystem.out.println(Utils.findKey(r, 99));    // nullRegistry<Integer, String> r2 = new Registry<>(); r2.put(1, "один");System.out.println(Utils.findKey(r2, "один")); // 1r.get("Анна");                               // Ошибка: Нет ключа: Анна
```

### Вариант 7. `Stack<T>` и `reversed`

**Класс `Stack<T>`** — стек, как в варианте 2, но упрощённый: внутри `ArrayList<T>`.

- `void push(T x)`, `T pop()` (на пустом — `IllegalStateException("Стек пуст")`), `int size()`;
- `toString()`: `Stack[a, b]`.

**Метод `static <T> List<T> reversed(List<T> list)`** — возвращает **новый** список с элементами в обратном порядке. Исходный список менять нельзя (в примере он остаётся прежним).

**Пример:**

```
Stack<String> s = new Stack<>(); s.push("a"); s.push("b");System.out.println(s + " size=" + s.size() + " pop=" + s.pop()); // Stack[a, b] size=2 pop=bList<Integer> src = List.of(1, 2, 3);System.out.println(Utils.reversed(src) + " исходный " + src);    // [3, 2, 1] исходный [1, 2, 3]System.out.println(Utils.reversed(List.of("x", "y", "z")));      // [z, y, x]
```

### Вариант 8. `Queue<T>` и `indexOf`

**Класс `Queue<T>`** — очередь, как в варианте 3, но с минимумом методов.

- `void enqueue(T x)`; `T dequeue()` и `T peek()` — на пустой бросают `IllegalStateException("Очередь пуста")`;
- `toString()`: `Queue[5, 7]`.

Покажите в `main`, что `peek` **не убирает** элемент, а `dequeue` убирает.

**Метод `static <T> int indexOf(T[] arr, T x)`** — индекс первого элемента массива, равного `x` (через `Objects.equals`), или `-1`, если нет.

**Пример:**

```
Queue<Integer> q = new Queue<>(); q.enqueue(5); q.enqueue(7);System.out.println(q + " peek=" + q.peek() + " " + q); // Queue[5, 7] peek=5 Queue[5, 7]System.out.println(Utils.indexOf(new String[]{"a", "b", "c"}, "c")); // 2System.out.println(Utils.indexOf(new Integer[]{1, 2}, 9));           // -1
```

### Вариант 9. `NumberBox<T extends Number>` и `sum`

**Класс `NumberBox<T extends Number>`** — коробка, в которую можно положить **только число** (`Integer`, `Double`, `Long`…). Запись `T extends Number` — это «ограничение типа»: `NumberBox<String>` уже не скомпилируется (проверьте и напишите в отчёте, какую ошибку выдал компилятор).

- конструктор `NumberBox(T value)`;
- `T get()`;
- `double doubleValue()` — значение как `double` (у любого `Number` есть метод `doubleValue()`);
- `boolean isPositive()` — `true`, если значение больше нуля;
- `toString()`: `NumberBox[5]`.

**Метод `static double sum(List<? extends Number> list)`** — сумма всех чисел списка. Запись `? extends Number` (wildcard) значит: «список чего-то, что является числом»; так метод принимает и `List<Integer>`, и `List<Double>`.

**Пример:**

```
NumberBox<Integer> n1 = new NumberBox<>(5);NumberBox<Double>  n2 = new NumberBox<>(-2.5);System.out.println(n1 + " " + n1.doubleValue() + " " + n1.isPositive()); // NumberBox[5] 5.0 trueSystem.out.println(n2 + " " + n2.isPositive());                          // NumberBox[-2.5] falseSystem.out.println(Utils.sum(List.of(1, 2, 3)));   // 6.0System.out.println(Utils.sum(List.of(1.5, 2.5)));  // 4.0// NumberBox<String> bad = new NumberBox<>("x");   // ошибка компиляции — закомментируйте и опишите в отчёте
```

### Вариант 10. `Maybe<T>` и `first`

**Класс `Maybe<T>`** — «значение или ничего». Это замена `null`: вместо того чтобы вернуть `null` и получить `NullPointerException`, метод возвращает `Maybe`, и вызывающий обязан подумать, что значения может не быть. (В Java есть готовый `Optional` — здесь вы пишете упрощённый аналог сами.)

- закрытое поле `T value` (в пустом `Maybe` оно `null`), конструктор `private`;
- `static <T> Maybe<T> of(T value)` — «с значением»; если передали `null`, бросает `IllegalArgumentException("null недопустим")`;
- `static <T> Maybe<T> empty()` — «пусто»;
- `boolean isPresent()`;
- `T get()` — значение; для пустого бросает `IllegalStateException("Значения нет")`;
- `T orElse(T other)` — значение или, если пусто, `other`;
- `toString()`: `Maybe[Java]` или `Maybe.empty`.

**Метод `static <T> Maybe<T> first(List<T> list)`** — первый элемент списка в `Maybe`; для пустого списка возвращает `Maybe.empty()`, **не** бросает исключение.

**Пример:**

```
Maybe<String> m = Maybe.of("Java");Maybe<String> e = Maybe.empty();System.out.println(m + " " + e);                       // Maybe[Java] Maybe.emptySystem.out.println(m.orElse("-") + " " + e.orElse("-")); // Java -System.out.println(Utils.first(List.of(7, 8)));        // Maybe[7]System.out.println(Utils.first(new ArrayList<String>())); // Maybe.emptye.get();       
```
